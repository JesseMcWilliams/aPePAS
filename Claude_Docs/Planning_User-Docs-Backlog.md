# aPePAS: User Docs Backlog

| Date | Change | User doc / section it affects |
|---|---|---|
| 2026-10-14 | Accounts now has a group menu between the category and its actions: Accounts, CPM tasks, Access and retrieval, Linked accounts, Dependent accounts, Discovered accounts. Groups with no actions for the system type (Dependent and Discovered on ISPSS) aren't shown. Action numbers changed | Interactive menu / Accounts actions |
| 2026-10-14 | `-Verbose` (or `-LogLevel VERBOSE`) on `Manage-Privilege.ps1` and `Invoke-AutomationWithCredential.ps1` writes every API call's request headers, response headers and response body to the log file (not the console). Credential headers show as `***` and password/SSH-key retrieval bodies are withheld. Log files get large on big lists | Troubleshooting / logging, parameter reference |
| 2026-10-14 | Onboard Discovered Account: give a DefaultPassword. A 14.6 PVWA fails the onboard with DAFWS005E without one, and the error now says so. The new account ID isn't returned; find it by username | Accounts / Discovered accounts |
| 2026-10-15 | CredentialSources.json: a profile's Params can have a Reason (CP and CCP; tokens {Profile}, {Category}, {Action}, {JobFile}, {JobDescription}, {Host}, {Date}) that shows in the PVWA audit when the driver retrieves the credential. A job file can carry a top-level Description. Needs the new aPeSecrets. | User-Guide: Credential sources |
| 2026-10-15 | Export All has a new IncludePendingAccounts option (Self-Hosted, off by default) that also saves the Pending (discovered) accounts to Export_AccountsListDiscovered.csv. It needs Vault Admins or PVWAAccountsFeedAdmins rights | Custom / Export All |
| 2026-11-06 | Add Account accepts platform properties: a `PlatformAccountProperties` column (`Key=Value;Key2=Value2`, for example `UseSudoOnReconcile=Yes`) and/or `Platform_<Key>` columns (for example `Platform_UseSudoOnReconcile` = `Yes`), the same names List/Get Accounts export. A `Platform_<Key>` column wins over the same key in the combined column. The interactive prompt asks for PlatformAccountProperties. Update Account takes the same columns (blank values leave a property unchanged), so existing accounts can be fixed from one CSV | Accounts / Add and Update, CSV input columns |
| 2026-11-11 | List Accounts has a Saved Filter (pick from a numbered list, or `SavedFilter` in automation, any case), for example `DisabledPasswordByCPM`, `ScheduledForChange` or `FailedVerify`. It combines with Search, Safe/Filter and By-Safe mode; an unknown name fails before any call. `DeleteInsightStatus` is Privilege Cloud only | Accounts / List |
| 2026-11-11 | List Accounts and Get Account show LastCPMModified, LastReconciled and LastVerified with the time (`yyyy-MM-dd HH:mm`), not just the date. CSV consumers that expected a bare date need updating | Accounts / List, Get; CSV columns |
| 2026-11-11 | Reconcile, Verify and Change Credentials Immediately have a Resume If Disabled option (`ResumeIfDisabled` Yes/No, default No). With Yes, an account the CPM disabled has automatic management resumed first, then the action runs. An account a user disabled is never resumed: a warning is logged and the action is sent as usual. WhatIf shows whether a resume would happen | Accounts / CPM tasks |
| 2026-11-06 | The end-of-session Session Summary no longer counts actions twice. CSV runs now show one entry per file instead of one per row plus the file total | Logging / Session Summary |
